# 游戏王卡包列表与详情页壳设计

## 状态

提案待评审。

## 背景

`site-yugioh` 已具备首页、搜索页、高级搜索页和卡牌详情页占位。首页的「卡包列表」入口指向 `app/pages/packs/index.vue`，当前仅渲染占位组件。本轮目标是先让卡包列表可用，并支持点击卡包进入一个详情页壳。

该工作与 desktop 卡牌数据导入管线相互独立：不新增数据库表，不改动 `yugioh`/`yugioh_data` schema，不依赖本地或远端 PostgreSQL。卡包数据采用静态落地方式，从公开数据源一次性抓取并固化到仓库。

## 目标

- 在 `/packs` 展示游戏王全部卡包，按 OCG / TCG 两个分区展示，样式延续 `site-yugioh` 当前的深色、细边框、橙金强调风格。
- OCG 卡包使用日文名称（数字+日文，如「ビヨンド・ザ・ブレイブ [BEYOND THE BRAVE]」），TCG 卡包使用英文名称。
- 每个卡包可点击，跳转到 `/packs/[id]` 详情页壳。
- 详情页壳展示卡包代号、名称、分区、发售日期和卡牌数量，并预留「该卡包全部卡牌」展示区域，本轮不接真实卡牌数据。
- 本轮不引入图标。

## 数据源实测

2026-08-07 对百鸽卡包列表页 `https://ygocdb.com/packs` 做了只读检查：

- 页面服务端渲染，含两个 tab：`#ocg` 与 `#tcg`。
- 共 2401 个卡包条目：OCG 1474 个、TCG 927 个，历史覆盖到 2006 年的奖品卡。
- 每个条目结构固定：`<li class="pack">` 内含发售日期、卡包代号、卡牌数量三个 `<span>`，以及指向 `/pack/{packId}` 的卡包名称链接。
- `packId` 为稳定且唯一的数字 ID（OCG 以 `1000…` 开头、TCG 以 `2000…` 开头），可作为路由 key。
- OCG 条目名称以日文为主（主卡包格式「日文名 [英文名]」，如「ビヨンド・ザ・ブレイブ [BEYOND THE BRAVE]」）；TCG 条目为英文名。
- 卡包代号在同一分区内不唯一（同一代号存在主卡包、+1 扩展、Sneak Peek 等变体），不能作为唯一标识。

数据源是可变化的外部输入。数量与重复情况只用于本次设计核对，不作为代码中的固定断言。

## 关键设计决策

### 路由 key 选择

详情页使用百鸽 `packId` 作为路由 key，而不是卡包代号或名称：

- `packId` 唯一且稳定，由上游直接提供。
- 卡包代号存在大量重复，无法唯一标识一个卡包条目。
- 名称含日文，slug 化后辨识度差且易冲突。

### 静态数据落地

在 `apps/site-yugioh/app/data/yugioh-sets.json` 固化全量卡包数据，字段为：

- `id`：百鸽 `packId`，作为路由 key
- `code`：卡包代号（如 `BETB`）
- `name`：卡包名称（OCG 为日文名，TCG 为英文名）
- `region`：`ocg` | `tcg`
- `cardCount`：卡牌数量
- `releasedAt`：发售日期，缺失时为 `null`

数据通过 `scripts/generate-yugioh-sets.ts` 生成，从百鸽 `/packs` 页面抓取、解析并校验后写回 JSON。生成脚本保留在仓库中，便于后续按需刷新卡包列表。

### 与卡牌数据同源

卡牌数据（`cards.zip`）与卡包列表均来自百鸽，未来实现「某卡包内全部卡牌」时可基于 `packId` 建立关联，避免跨数据源对齐代号的不确定性。本轮不实现该关联，详情页壳仅展示卡包自身的静态信息。

## 页面结构

### `/packs`

- 页面标题与说明。
- OCG / TCG 两个分区 tab，默认展示 OCG。
- 每个分区内卡包网格：每个卡包一个卡片，显示 `name`，副信息显示 `code`、`cardCount` 与发售日期。
- 整个卡片可点击，跳转 `/packs/[id]`。
- 数据来源：`app/data/yugioh-sets.json` 直接 import。

### `/packs/[id]`

- 顶部返回 `/packs` 的链接。
- 卡包基本信息：`code`、`name`、`region`、`cardCount`、`releasedAt`。
- 「卡牌列表」区域展示为占位状态，说明后续接入。
- `id` 未命中时展示轻量未找到状态。

## 范围限制

- 不接数据库。
- 不接运行时外部 API。
- 不实现卡包内卡牌关联。
- 不新增图标。
- 不改动 `site-yugioh` 现有页面与样式体系。

## 验收标准

- `/packs` 渲染 OCG 与 TCG 两个分区，分区内网格可滚动展示。
- 点击卡包进入 `/packs/[id]`，展示对应卡包信息。
- 未知 `id` 显示未找到状态。
- 生成脚本可重复运行并覆盖数据文件。
- `bun --filter site-yugioh lint` 通过。
