# 0015: Cards carry a universal ambit (primary/additional/full) that scopes search

Search on every game site needs a scope hierarchy: unscoped search mixes tokens, display cards, and UI helper entities into results nobody wants. Every game's cards are therefore classified by the minimum **ambit** at which they enter the card pool — `primary` (normally encountered and directly obtained or played), `additional` (in-game derivatives of, or attachments to, other cards), `full` (never appears in a game at all). The ambit is a property of the card, not a search setting: stored as a same-named column with one shared enum on every game's card tables; a query selects an ambit as the ceiling and sees every card at or below it, defaults to primary, and widens stepwise (primary → additional → full) only when the query does not pin an ambit explicitly. This replaces the Hearthstone-only hardcoded "default visible card" filter with a cross-game model, and deliberately admits Battlegrounds standing components (tavern spells, quests, trinkets, anomalies, Darkmoon prizes) and mercenary mains into primary — they are never collectible in the data, but they are standing, discussable fixtures of their mode, which is the axis that matters.

## Considered Options

- **Naming.** `tier` (bland), `scope` (collides with the task system's task scope), `core` (collides with Hearthstone's Core Set and MTG Core Sets), `supplemental` for the middle level (collides with MTG's official "Supplemental Sets" product category, and names a relation rather than a rung), `peripheral` (rejected for sharing its initial with `primary`). Landed on `ambit` with `primary/additional/full`.
- **DSL syntax.** A `@` meta-command namespace and a private sigil for ambit were both rejected as premature structure: the DSL already has a behavior-side command precedent (`collectible:`), typed `ambit:` queries are low-frequency (absence means primary), and special syntax should arrive together with the second meta command. `collectible:` stays as an independent field filter alongside the new `ambit:` command.
- **Hearthstone default view.** Keeping the old exclusion of Battlegrounds from the default view was rejected: with BG fixtures ruled primary, default search is primary wholesale, and the old "default visible card" term retires.

## Consequences

- Five card tables gain the column (`hearthstone.entities`, `magic.cards`, `yugioh.cards`, Shadowverse Beyond `cards`, `evolve_cards`); the enum lives in the shared model. Magic's values are auto-seeded by projection from source signals with manual overrides stored in `magic_data` as the authority, keeping `cards.ambit` a rebuildable fact. Yugioh and shadowverse predicates are defined on paper only and finalized in those games' own design efforts — their published card tables are still empty.
- Card-domain consumers beyond search (random cards, related cards) can reuse the same classification instead of inventing their own visibility rules.
