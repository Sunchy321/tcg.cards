# 炉石前端与 dev 后端同步修复

## 背景

`dev` 合入后，炉石后端和数据模型发生了较大变化，当前 `site-hearthstone` 的前端页面、搜索命令和详情接口仍有部分旧模型假设，导致 `typecheck` 和 `lint` 失败。

## 范围

- 修复炉石详情接口与新实体/关系模型之间的类型不匹配。
- 修复炉石搜索命令对 `mechanics` 和 `referencedTags` 的 JSON 字段查询方式。
- 修复详情页、搜索页、卡图组件等前端类型错误。
- 清理阻塞 `site-hearthstone lint` 的格式问题。

## 非目标

- 不重做炉石页面视觉设计。
- 不新增业务功能。
- 不调整数据库结构或迁移。
- 不处理与本次检查无关的其他站点问题。
