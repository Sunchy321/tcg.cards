## 当前交付限制

本次提交包含远端迁移，不包含本地迁移。本地迁移生成时，Drizzle 检测到万智的历史结构差异：旧迁移和实际本地数据库已有 `magic_data.mtgch_zhs_card`，最新本地快照却记录 `magic_data.mtgch`。生成过程停在新建或重命名表的交互提示，未执行相关数据库变更。该历史问题交由维护者处理，随后需要补齐游戏王本地迁移；在此之前，不能将本次提交视为已完成本地数据库升级。

1. 在 `yugioh` schema 新增 `card_localizations` 与 `card_name_variants`，将所有语言相关列从 `cards` 移除。
2. 在导入阶段为每张卡构造简中、日文、英文三条本地化记录，并构造去重后的中文名称变体。
3. 扩展发布清单、哈希和恢复账本，使卡、本地化、名称变体作为一个一致快照发布到远端。
4. 在数据表上建立主名称及名称变体的检索索引；游戏王站点尚未接入数据库查询，因此不在本次新增站点 API。

6. 在提交阶段运行 Drizzle 生成命令，为 local 与 remote 各生成至多一份迁移，并核对数据回填 SQL。
