# 影之诗 Beyond 卡牌数据导入设计评审

## 评审记录

评审于 2026-08-30 通过逐项问答完成，设计方向与各决策点均已由用户确认。

| 决策点 | 结论 |
| --- | --- |
| 先做哪个模式 | Beyond（超凡世界）；Evolve 另立提案 |
| 数据来源 | 以官方站点为主（shadowverse-wb.com Deck Portal 接口） |
| 第一期范围 | 全量：卡牌数据 + 卡图 + 五语言本地化（日/英/简中/繁中/韩） |
| publish 到远端 | 第一期不做；当前仅能在分支工作、无法合入主干，远端发布不具备实际执行条件，条件具备后另立提案 |
| token 卡 | 包含入库（`include_token=1`） |
| 卡面样式（异画） | 数据与异画卡图（含进化样式图）均导入 |
| 卡包元数据 | 接受暂无发售日，站点先用导入数据 |

## 数据源验证

design.md 中的接口结论（`/web/CardList/cardList` 端点、`Lang` 头五语言、`offset` 分页、`include_token`、按语言独立的卡图 hash 及卡图 URL 规律）均通过实际请求验证，验证日期 2026-08-30。

若官方接口后续变更（路径、参数、响应结构），导入实现会失败并暴露问题，届时需重新验证并更新 design.md。

## 遗留事项

- Evolve（实体 TCG）模式的数据导入另立提案，本 spec 不覆盖。
- publish 到远端在分支可合入主干后另立提案。
- `skill_text` 自定义标记（如 `<color=Keyword>`）的站点渲染属于站点侧后续工作，不在本 spec 范围。
- 进化图与样式图的确切资源子目录在实现期以实际请求为准（design.md 数据源章节已注明）。
